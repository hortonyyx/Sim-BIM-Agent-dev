正常 `build_bim` 的既有 source enclosure 能力已用无案例答案合成夹具验证：真实屋面空气/维护空间＋开放顶＋实体周墙，3 空间、真实机房门、source pass，无需假造薄墙体房间；角色不等于人数/热负荷。但 parametric 主入口无 enclosure 直达字段，generic 路线要求采用后源摘要绑定，实际引用说明未给足可直接使用的方法。

原生开放围护为 source_bim_v3，与本次冻结的 v2 schema/额外字段限制不兼容。v2 `kind=virtual` 理论能表达整块开放顶，但不能普遍剥掉 v3 字段降级，尤其 partial open/unknown/依据不可丢失。合成 v2 witness 在公共 renderer 填充模式下进入缺省 physical/opacity=1 普通面代码路径，没有专门 virtual 处理；未启动浏览器，不宣称任意视图必然实心封顶。该兼容问题没有在 B 实际尝试中触发，不能据此免除它的真实形体遗漏。

## 未决与后续

四次生产筛选与独立评阅均已终态，当前无建模进程。四份独评均不通过，没有一条已证实满足全部目标的路线。各次均无人工补提示，B 未见 A 的输出或评阅。最后两项离线修复不能回写旧实测成绩。

压缩回执、合法原组件的保守采用、交付收尾、已有开放围护能力的可达性与统一 materialization 应分别验证，不能通过改评分或放宽质量阈值掩盖不足。完整回执压缩 8.51% 不足以支持“快一半”。自研 runtime 的 C 组、未见输入泛化、较便宜模型、真实仿真及生产分工尚未开展；先解决单 Agent 路线的已证实阻碍，不扩大本轮结论。

下一轮优先级据本次结果调整如下，均未宣称已经实现：

1. **将建筑意图和几何合法性接起来。** 模型决定用途、相邻、必要通达和证据；工具帮助构造共用宿主、门及可用路径，返回局部失败证据。先用不同朝向/尺度的合成案例验证，避免为利苑写坐标答案。实际门宽、通路瓶颈与入口侧应进入合理性核查材料，不能仅靠 connections 图，也不把逐条法规硬编码当通用建筑判断。
2. **让已有表示能力可直接使用。** 真实开放屋面及维护空间、围护与源 BIM 版本/公共渲染一致；模型不应在“省略可见形体”和“虚构占用房间”之间选择。统一合同变更需两臂同时采用，不能事后替 B 放宽出口或剥掉语义。
3. **减少首稿前表示和修复工作。** 在已有薄 SDK 上验证共享关系/简单几何的少量可组合表达、合法组件的保守采用与一次聚合诊断。默认完成材料直接随候选提供，收尾按已选候选绑定完成，不让模型重复查清单。减少模型回合才可能比单纯减短回执有数量级更大的收益；仍须实测。
4. **候选通过窄验后再做冻结筛选。** 当前没有合格候选，不做三次正式重复来放大已知失败，也不提前把 C、较便宜模型或生产分工当作补救。后续统一依赖版本和合同，先验证两案质量与速度，再执行原计划的匹配重复；10/5 分钟目标不变。

本轮完成的是第一批实施、反证与缺陷定位，不是整个 P0–P6 计划或毕设价值证明的完成。
