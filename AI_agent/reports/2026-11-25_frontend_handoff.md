## 已定的交互与数据

| 环节 | 当前行为 |
| --- | --- |
| 录入与模型 | 每个素材组按编号保存 PNG、GLB 或声明 JSON 和可选说明；文件复制进工作区。Task kickoff 是用户的建筑概况，系统建模规则另行注入。可选主控和多个 worker，已接 ChatGPT 订阅、DeepSeek 官方 API 及自定义 OpenAI 兼容 Chat Completions 连接。 |
| 运行与交付 | Run 冻结本次输入，工作台展示实际 Harness 轨迹，完成后打开一个 Sim-BIM HTML。过程文件与检查留在工作区。独立 HTML 默认英文，网页可随工作台语言打开。中英文界面共享 `G`、`U`、`O01` 等楼层码和英文构件名。网页预览按交付版本加载。 |
| Model 与 Confidence | 左侧信息卡分别对应空间、楼层、表面和边线。置信度描述空间几何，按空间或表面着色；选楼层时按空间，选边线时按表面。五档紫色色卡中越紫代表推断越多，切入时透明度为 75%。空间和表面可展开双语理由。 |
| 仿真属性 | 空间记录房间类型。表面记录主构造材料的简短观察与厚度，来源为 `from material`、`inference` 或 `from user`。材料、厚度各自在标题行显示来源、下一行显示值。厚度候选分墙、水平分隔、屋顶、玻璃四组，支持多选或回车添加自定义毫米值。楼板与顶棚共组，共享构件按对应区域读取厚度；玻璃取玻璃单元总厚，门厚由模型填写。分层构造留给后端插件。 |
| Edit | 可选空间、楼层、表面，Ctrl 加选，选区以红色显示。点勾确认后，批注保留对象与点击位置；左侧可补充整栋调整说明。指北针支持拖动或键入，按 5° 吸附，确认后保存。已确认的改动保存在当前浏览器的本地草稿。 |

管线共用五档标准。5 档为直接证据确定本对象的位置和主要尺寸；4 档为仅需小幅估计，或已有模板且有证据证明本层适用；3 档为几何部分已确定、主要范围仍需推断；2 档仅有异层或类似空间作间接依据；1 档为缺乏适用定位或尺寸证据的假设。空间、表面、开口分别判断，主材与厚度另用来源标签。[管线标准](../../scripts/tool_scripts/bim_agent_guidance.py) · [界面与数据验收记录](2026-11-24_workbench.md)
