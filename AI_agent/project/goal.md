# 产品目标

**Sim-BIM Agent** 接收建筑资料，生成统一的 Sim-BIM，供查看、修改和后续分析。当前使用版支持 PNG 图纸与带贴图 GLB，可附带文字或 JSON 声明，输出结构化 JSON 和 HTML 查看器。

## 产品方向

不同模态逐步汇入同一个建筑数据模型。后续可讨论 CAD、实景照片、其他模型和 Grasshopper 等输入；尚未实现的模态不写成当前能力。可视化输入和模型 API 配置界面是后续产品化工作，本次清理不增加前端。

使用版应能独立安装和运行，目录职责清楚，命名和说明一致，配置与错误信息可理解。开发库保留当前源码、必要检查与维护工具，退役实现通过 Git 历史追溯。

## 主线价值

- **更快**：在相同模型、配置和输入下减少完整交付的时间与无效往返。
- **更好**：提高建筑空间、几何、开口宿主、连通与推断合理性。
- **更省**：降低对强模型的依赖，让较弱模型也能承担合适工作；token 数量不单独代替成本与价值。

模型、runtime、领域知识、代码工具及分工分别评价。后续继续讨论 runtime 的取舍、领域内容的形式、不同模型的适配与分工方案，不把现有实现当成最终架构。

## 证据与验收

运行稳定、完整交付、建筑质量与效率分别提供证据。输出几何自洽不等于正确理解原图；模型自检不等于独立质量评价。允许标注清楚的假设和简化，不能用虚构依据填补缺失资料。

发布从开发库更新桌面并验收，再把同一份桌面程序发布云端。本次任务和验收案例以 [项目入口](../Agent.md) 为准，历史实验事实按相关工作记录追溯。
