## 产品与质量

- 输入资料最终统一输出 Sim-BIM JSON 和 HTML 查看器。空间划分、开口宿主、连通、几何与依据应有明确数据边界。
- 当前几何、角色与工具能力不能仅凭目录旧名称删除；先确认调用与数据合同，再保留现役实现、退出退役功能。
- 不用兼容壳、包级自动导入或错误忽略维持已经退出的设计。
- 几何一致性、模型完成、建筑质量、效率和服务稳定性分别报告，不互相代替。
- 输入资料、用户声明和模型假设分开记录；GT、旧答案和评测资料不进入工作模型输入。
- Zone 的水平和竖向边界，大部分应能对应已观察或合理推断的物理分隔。外立面分带可以支持外形判断；推断整层楼板、夹层或室内隔墙还需要与这些构件相符的证据。优先按平面核对真实楼梯、门与前室。
